# FinTwin knowledge base

Short explainer notes the research tool retrieves from. One file per topic,
one `##` section per retrievable passage. The first line of each file is its
provenance and is attached to every passage as the Evidence source.

Rules for adding notes:

- Plain, checkable statements. No predictions, no stock tips.
- Mark approximate historical figures as approximate, and name where they can
  be verified.
- Keep sections short (a paragraph or two); retrieval works per section.
